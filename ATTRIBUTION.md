# Source attribution / 来源署名

Any integration using **FCC Core** or **FCC Skill** should visibly credit the source as required by `LICENSE`:

> Powered by FCC Control Studio — Chans (chenchen_wang@foxmail.com)

- **AI agents:** When FCC is used to produce user-facing control summaries or reports, include this credit in a source/provenance section (or an accessible credits page for products).
- **SDK / API integrators:** Include the credit in the application's About/Credits, public documentation or associated output provenance.
- **CLI or internal tools:** Include the credit in the README, integration documentation or machine-readable provenance metadata.
- **Source redistribution:** Keep both `LICENSE` and `NOTICE` and document your modifications.

This is a custom attribution-required source-available license, **not** a standard OSI-approved open-source license. A normal copyright statement, a `NOTICE` file alone, or a Git commit author field would **not** impose the same runtime-attribution condition.

For **every integration** using the API or Skill, keep visible provenance. A single accessible credits location for a product satisfies repeated runtime calls as detailed in LICENSE; requests themselves need not contain the credit.
