# FCC 1.2 高级控制：接口、边界与设计审查

## 基础与新增对应关系

- 理论典型主题：动态系统、线性系统特征值、极点配置、PID、确定性观测器、采样数字控制、Lyapunov/频率域。
- 额外先进控制：MPC / LQR 属最优控制；KF/EKF/UKF 属随机状态估计；RLS 与在线自校正属自适应控制。这些方法分别属于现代最优控制、随机估计及自适应控制分支，不能与软件工程模块混为一谈。
- 软件工程：角色/审批、时钟、版本、人工反馈、数据归因、可验证和回滚。

## MPC（`ConstrainedMPC`）

`ConstrainedMPC(model, horizon, Q, R, S, Qf, u_min, u_max, du_min, du_max, y_min, y_max)`。

线性离散模型需要确定 `A/B/C/D/Ts`；代价：输出轨迹跟踪、输入幅度、输入变化率和输出终端权重；SLSQP 有限时域数值优化，每轮重新求解，仅应用首个控制量。

- `Q`: 输出代价 PSD `(p,p)`，`R`: 输入代价 PD `(m,m)`，`S`: 输入变化 PSD `(m,m)`；`Qf`: 输出终端附加代价。
- 输入 `x0:(n,)`, `reference:(p,)` 或 `(N,p)`, `u_prev:(m,)`。
- 约束可以按 m/p 分别给出；求解失败、不满足数值约束时抛异常、不输出待执行动作。
- **不包括**：可行域终端约束、鲁棒管状 MPC、概率约束、递归可行性保证、扰动观测器、非线性 MPC、稳定性证明。
- 引擎控制器 `kind=mpc` 适配 SISO（m=p=1）；其他 MIMO 数学规划可从 Python 调用，但执行需扩展适配器。

## Kalman（`DiscreteKalmanFilter`）

离散线性高斯假定 `x[k+1]=Ax[k]+Bu[k]+w`, `y[k]=Cx[k]+Du[k]+v`，需要正确估计的 `Q=Cov(w)`, `R=Cov(v)`。初态提供 `x0, P0`。

支持 `predict(u)`、`update(y,u,gate_nis)`；Joseph form 协方差传播；按通道缺失值 `None/NaN`、基于 NIS 的全次采样拒绝。`gate_nis` 是用户按测量维度设置的**绝对 NIS 门限**，不是直接用 0.95 这样的概率阈值；门控只表明统计不一致，不自动确定传感器或模型哪个有问题。

## EKF / UKF（数学 SDK）

- EKF 需要 `f,h,jac_f,jac_h`，一阶线性化；非线性强/初始偏差大时容易发散。
- UKF 需要 `f,h`、加性噪声 `Q/R`、sigma point 参数 `alpha/beta/kappa`；支持整体 NIS 门控。数值半正定校验不能替代非线性模型准确性。
- 两者都不直接暴露为 JSON 内的可序列化函数；如果要供远程 Agent 使用，必须由可信服务方注册函数/模型标识，而不能允许客户端提交任意 Python 代码执行。

## 离散 LQR

`discrete_lqr(model, Q, R)` 用 DARE 计算 `K`、`P` 和闭环极点，仅是 `u=-Kx` 的调节器。需有可稳定化系统、合理权重及实际执行保护。跟踪非零参考需额外参考跟踪/稳态求解。

## RLS + SelfTuningARX

- RLS 对 `φ=[y[k],u[k],1]` 拟合 `y[k+1]=a*y[k]+b*u[k]+c`；`forgetting_factor ∈ (0,1]`。
- 自校正根据 `a,b,c` 计算下一步输出跟踪的建议输入，要求足量有效时序样本、有辨识激励、控制增益方向明确、输入变化/绝对幅度硬限制。
- 内置 `AdaptiveARXController` 默认 **monitor-only**：配置 `trusted_applied_input=true` 后方可开始适配器输入历史辨识，要求 `actuator.action_range` 和 `max_step`。高风险自适应动作一律人工审核。
- 不包括 MRAC、鲁棒参数投影、增益随时间的稳定性证明、对漂移对象的生产级在线控制保证。

## 调度

- `mode=fixed/adaptive/cron` 可由 `Engine.tick` 触发。
- `adaptive` 根据最近一次有尺度的误差和不确定性调整检查间隔，不修改控制器参数；只有可归一化的 tolerance 才进入 severity 计算。
- 5 字段 Cron 可用 IANA 时区，支持 `*`, `*/n`, 范围和列表；Quartz 扩展/秒级表达式不支持。
- `TrendTrigger` 是对新可信数据调用的斜率判定器，未在引擎中实现自动新样本订阅。

## 先决条件清单（高风险场景必须满足）

1. 系统输入 `u` 和输出 `y` 单位、符号、动态响应经独立试验验证。
2. 模型阶数、离散采样周期、时延/扰动、辨识数据覆盖控制工作区间。
3. KF 的 Q/R/P 通过独立噪声样本验证；观察 NIS 残差，不能把滤波输出称为真实测量。
4. MPC 在多种扰动、参数误差、约束边界上测试可行性和闭环性能；部署前设置执行级联锁。
5. Adaptive 的执行量来自实际回读/真实日志，不是模型推荐值；盲测验证模型、启发/限制额外保证。
6. 控制器产生的动作先进入人工审批；新观测到来后独立验证，不因求解成功而报任务成功。
7. 网络服务的认证、最小权限、秘密管理、隔离、备份、监控属于外部部署责任。
