# FCC 1.3 通用 I/O 面板：用户操作指南

## 1. 一分钟跑通

1. 解压 `FCC-Core-v1.3-IO.zip`，进入 `fcc-core` 目录。需 Python 3.11+。
2. Windows：双击 `启动FCC-Windows.bat`（需有可用 `python` 命令）。Mac/Linux：在终端运行 `bash 启动FCC-Mac-Linux.sh`。第一次运行会尝试安装依赖，需要网络；也可手动 `python -m pip install -e .`。
3. 浏览器打开 **http://127.0.0.1:8099/**，看到 `FCC Core 已连接`。
4. I（Input）依次填：名称、指标 ID、目标值/目标区间、允许误差、当前观测值及来源。内置的 100、85、±5 仅为演示。
5. C（Control）默认选“只分析偏差”，点击 **运行一次 · 获取反馈结果**。
6. O（Output）看到目标、观测、误差、是否超出容差、建议状态，以及是否已经有独立验证证据。换一个新的实际观测值并再次运行，即可积累历史。
7. 点击“复制 I/O 配置与 AI 接入提示”，粘贴到支持读取独立 FCC SKILL 的其他 AI Agent；SKILL 自身不会代替 Core 运行控制数学算法。

如果不想使用启动脚本，可以手工运行：

```bash
cd fcc-core
python -m pip install -e .
python -m fcc.server --host 127.0.0.1 --port 8099 --db fcc.db
```

- 开放的 API 文档：`http://127.0.0.1:8099/docs`
- 专家控制台：`http://127.0.0.1:8099/expert`

## 2. I/O 字段对照

| 用户看到的名称 | 内部字段 | 意义 | 必填 |
|---|---|---|---|
| 回路名称 | `name` | 用于区分不同任务或系统 | 是 |
| 指标标识 | `target_variable` / `metric_id` | I/O 两端都使用的固定字段名 | 是 |
| 目标值 / 范围 | `setpoint` | 希望达到的 r | 是 |
| 允许误差 | `tolerance` | 达标判断的宽限幅度 | 目标值模式必填 |
| 当前观测值 | `value` | 实际观察到的 y，不是目标或预测 | 每次检查必填 |
| 数据来源 | `source_type` | 人工 / 实测 / AI 推断 | 是 |
| AI 置信度和证据 | `confidence`、`evidence` | AI 推断的必要附带元数据 | 使用 AI 时必填 |
| 反馈方式 | `controller.kind` | `monitor` 或有条件的 `threshold` | 是 |
| 反馈频率 | `scheduler` | 手动或固定周期评价 | 是 |
| 输出建议 | `proposed_actions` | 仅控制器建议，不等于已执行 | 自动生成 |
| 效果验证 | `verification_status` | 必须分清待验证 / 已验证 | 自动生成 |

**数学边界**：在单点目标上 `e = r - y`；区间目标误差按目标区间判断，不必把区间硬转成单点值。单纯的“当前偏差”不能自动确定物理系统应调整的控制量 u。阈值建议模式需要用户事先确认执行量定义、量纲、作用方向、上下界及动态响应，且简易面板仍只提出建议。

## 3. 用户最常问的问题

**我每次都要创建新回路吗？** 不需要。选择已有的“简易回路”，只修改当前观测值时会复用原回路；修改目标、名称或策略会创建新回路，保留旧记录，防止历史串线。

**周期检查会自动采集数据吗？** 不会。可点击“启动周期检查”启用定时评价，但数据采集必须由传感器/SDK/API 外部接入。否则可能遇到过期数据警告。

**这算 AI 自我纠错吗？** 默认不算。它会保存差异与控制建议。只有执行已授权的动作、得到新的可信观测并验证，才能判断改善与否。

**为什么不能任意任务都直接使用 MPC？** MPC、Kalman 都要求有效数学模型、采样时间和噪声/约束参数。非数值任务应先定义可验证的数值代理指标，或通过自定义适配器处理动作；不能凭一个自然语言目标推断动力学模型。

**既然是通用模块，为什么简易面板只支持一项数值指标？** 通用性指 Core 和 SKILL 的抽象接口不绑定行业；易用界面优先把最常见的单指标监测流程做好。多目标/MIMO 的数学库已有部分实现，但内置执行链不等于完整 MIMO 端到端控制。

## 4. 安全提醒

默认只生成建议 (`suggest_only`)，HTTP 服务没有鉴权；请只在本机使用 127.0.0.1。涉及设备、资金、生产数据和不可逆动作必须在业务系统实施独立的权限控制、执行联锁、日志审计及回滚验证。
