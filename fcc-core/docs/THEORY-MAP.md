# Control method classification and limitations

This document describes algorithm categories without claiming any single textbook as the origin of this repository.

**Classical control:** dynamic state-space models, stability of known LTI systems, observability/controllability, PID, pole placement, frequency analysis and sampled-data control.

**Advanced optimal/estimation/adaptive tools:** finite-horizon MPC, Kalman/EKF/UKF, discrete LQR, recursive least-squares estimation and safeguarded ARX self-tuning.

**Application-level engineering:** onboarding, data freshness, operator approval, notification scheduling, logging, before/after review and rollback.

Mathematical results concern a specified model. They are not blanket guarantees for unknown real-world processes. A simulated improvement is not proof of a deployment's safety or effectiveness.
