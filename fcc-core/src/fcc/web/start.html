从一个目标开始，建立可验证的持续反馈。

无需先理解控制算法。选择你正在使用的 AI 类型，系统会告诉你：应该提供哪些信息、当前可以真正运行哪些能力，以及哪些功能还需要部署。

模式 A · 仅有聊天 AI

把 SKILL 交给你的 AI

适合只能上传文件、没有本地终端或后台运行权限的 AI。

1上传 fcc-skill 文件夹或整个整合包。
2让 AI 读取 SKILL.md，逐项询问目标、测量、数据、反馈节拍和执行边界。
3AI 生成计划和阶段复盘模板；后续需要你提供新数据，除非另外连接了真实的后台服务。

仅导入文档不会让聊天 AI 自动运行定时任务，也不会自动发送提醒。

模式 B · 能运行本地命令的 AI Agent

检测环境并启动 Core

适合可以读取源码、运行 Python、访问本机 API 的编码代理。

1执行只读检测命令，获取 JSON 能力报告。
2只有用户明确授权后，才安装依赖、以前台方式启动本地服务。
3打开向导，提交观测，安排周期检查并在本地收件箱查看报告。
python fcc-skill/scripts/fcc_bootstrap.py doctor --json
进入需求设置

服务器进程退出后，后台调度也会停止。要主动发送消息仍需独立通知连接。
