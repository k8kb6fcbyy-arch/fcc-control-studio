# Control methods: mathematical versus software engineering

- **Classic mathematical models:** linear state space, PID, pole placement, observer design, time and frequency response, stability conditions.
- **Advanced numerical methods:** MPC, Kalman, EKF, UKF, LQR, RLS and ARX adaptation.
- **Software orchestration:** agent interviews, user consent, data ingress, scheduling, reports, audits and recovery.

The availability of a numerical method is not evidence of a validated system model or production-grade integration. Do not infer physical actuator access from a user's textual goal.
